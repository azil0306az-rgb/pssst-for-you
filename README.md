# 🎁 “PSSST… THIS IS FOR YOU”
### An Interactive Birthday Surprise Experience

A visually stunning, mobile-first, emotional and playful digital birthday surprise crafted for your favorite menace and best friend.

---

## ✨ Features & Story Scenes

1. **Scene 1: The Secret Arrival**
   - Midnight plum starry universe with animated dust particles and drifting hearts.
   - Cinematic staggered whispers revealing secret message line-by-line.
   - "TOP SECRET ★" badge and subtle sound cue.

2. **Scene 2: The Interactive 3D Gift**
   - Real CSS 3D illustrated gift box with wrapped ribbons, a volumetric 3D bow, and glowing particles.
   - Responds to pointer movements with 3D tilt.
   - On tap: rattles, loosens ribbons, pops the lid open with a flash of light, bursts confetti and hearts, and smoothly transitions the scene.

3. **Scene 3: The Birthday Reveal**
   - Atmospheric shift from midnight plum to soft cream, blush pink, and lavender gradient.
   - Dramatic headline: *"OKAY, LISTEN UP, BITCH. ♡"*
   - Scrapbook stickers, tilted declarations, and smooth scroll down to the letter.

4. **Scene 4: The Heartfelt Birthday Letter**
   - Realistic floating paper sheet with subtle texture, soft shadows, washi tape, and heart stamp.
   - Scroll-triggered paragraph fade-in with the exact heartfelt message.
   - Floating handwritten scrapbook annotations:
     - *“Certified chaos partners.”*
     - *“Annoying you forever is my legal obligation.”*
     - *“Friendship level: concerning.”*
     - *“You are stuck with me. Sorry, not sorry.”*
   - Animated handwritten signature: *“Your bitch for life ♡”*.

5. **Scene 5: The Interactive Chaos Zone**
   - **Card 1: A Very Important Reminder** — interactive envelope with wax seal that opens and pulls out a secret note.
   - **Card 2: Your Official Birthday Award** — 3D trophy with sparkles, expandable certificate, and "Accept Your Award" button with celebratory confetti.
   - **Card 3: Unlock a Secret** — locked treasure chest with glowing light beam that unlocks to reveal a deeply moving promise.
   - **Card 4: Tap If You Love Me** — glowing interactive heart that scales, bounces, sprays hearts, and updates through humorous escalations on every tap.

6. **Scene 6: The Birthday Wish Generator**
   - 3 interactive cards with 3D flip animation:
     - *"MAIN CHARACTER ENERGY"*
     - *"UNREASONABLE HAPPINESS"*
     - *"UNLIMITED CHAOS"*

7. **Scene 7: The Hidden Easter Egg**
   - Sneak trigger badge in the top bar.
   - Dims screen into a starry night sky and displays an emotional secret letter.

8. **Scene 8: The Grand Finale & Wish Orb**
   - Cinematic headline: *"HAPPY BIRTHDAY, YOU BEAUTIFUL DISASTER. ♡"*
   - Interactive 3D glowing Wish Orb with orbiting celestial rings.
   - "I Made My Wish" triggers a multi-wave grand finale celebration.
   - "Replay Your Little Surprise ↻" smoothly resets the experience without refreshing the page.

9. **Audio Design**
   - Built entirely on the **Web Audio API** — 100% offline, zero latency, zero broken external audio URLs, and works on all mobile and desktop browsers.
   - Optional sound toggle (starts muted by default per modern browser autoplay standards).
   - Generates ambient music-box melodies and custom procedural SFX for unboxing, pop, confetti, plucks, and celestial bells.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 🌐 One-Click Deployment (Vercel / Netlify)

### Deploy to Vercel:
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Framework Preset: **Vite** (Build command: `npm run build`, Output directory: `dist`).
4. Click **Deploy**!

### Deploy to Netlify:
1. Drag and drop the `dist` folder into Netlify Drop, or connect the Git repository with publish directory set to `dist`.
